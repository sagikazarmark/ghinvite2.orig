# 404 Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render route-aware HTML 404 pages for public, recipient-flow, and validated account-console page misses without weakening generic 404 security behavior.

**Architecture:** Add a reusable Dioxus not-found view module and keep layout selection in the routes that have safe context. Add a public fallback route for page misses, render recipient-flow 404s from invitation GET handlers, and add a dashboard wildcard GET route that uses `RequireAdminOf` before showing account-console chrome.

**Tech Stack:** Rust 2024, Axum 0.8, Dioxus 0.7 SSR, tower-sessions, Tailwind CSS v4, DaisyUI v5, `cargo test -p web`, `npm run build:css` in `crates/web`.

---

- Modify `crates/web/src/views/mod.rs`: export the new view module.

- Modify `crates/web/tests/route_smoke.rs`: cover public fallback, recipient-flow 404, and plain static asset 404 behavior.

```rust
use crate::error::WebError;
use crate::views::render::render;
use axum::body::Body;
use axum::http::{Method, StatusCode, Uri, header};
use axum::response::{Html, IntoResponse, Response};
use dioxus::prelude::*;

pub async fn public(method: Method, uri: Uri) -> Response {
    if method != Method::GET && method != Method::HEAD {
        return plain_not_found();
    }

    if uri.path().starts_with("/static/") {
        return plain_not_found();
    }

    if method == Method::HEAD {
        return (
            StatusCode::NOT_FOUND,
            [(header::CONTENT_TYPE, "text/html; charset=utf-8")],
            Body::empty(),
        )
            .into_response();
    }

    let html = render(|| {
        rsx! {
            crate::views::not_found::PublicNotFoundPage {
                signed_in_login: None::<String>,
            }
        }
    });
    (StatusCode::NOT_FOUND, Html(html)).into_response()
}

fn plain_not_found() -> Response {
    WebError::NotFound.into_response()
}
```

```rust
fn session_cookie(resp: &axum::response::Response, fallback: Option<String>) -> String {
    resp.headers()
        .get("set-cookie")
        .map(|v| v.to_str().unwrap().split(';').next().unwrap().to_string())
        .or(fallback)
        .expect("session cookie available")
```
